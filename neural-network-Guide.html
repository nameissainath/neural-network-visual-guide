Weight & Bias
💡 WHY: Weights and biases are the only learnable parameters. Everything else in the network is fixed math. Training = finding the right values for these.
🚕 UBER FARE — EXACT SAME FORMULA
Total Fare = (Price per km × Distance) + Base Fare

Price per km = WEIGHT — sensitivity of output to input
Base Fare = BIAS — fixed offset regardless of input
Distance = INPUT — data fed into the network
Same Formula — House Price
Price = (W_loc × Location) + (W_sqft × Sqft) + Bias = (0.5 × 7) + (0.3 × 1000) + 10 = 3.5 + 300 + 10 = 313.5 Each input has its OWN weight. Bias is ONE value added at the end. Both start RANDOM and are fixed through training.

4
Backprop + Weight Update — Animated
💡 WHY: After forward pass gives a wrong prediction, backprop flows BACKWARDS assigning blame (gradients) to each weight. Then gradient descent uses those gradients to update every weight.
Step ① — Forward Pass Complete
Forward pass complete: LOC=7, SQFT=1000 → L1 → L2 → L3 → Output = 267 Predicted = $267k Target = $200k Network is $67k too high. Now go BACKWARDS to find which weights caused this.
Step ② — Compute Loss
Loss = (Predicted − Target)² = (267 − 200)² = 67² = 4,489 This is our error score. Backprop will now find WHO caused this 4,489.
Step ③ — Backprop Signal Flows Backwards
← Red signal travels from Loss back to every weight Loss → Output → Layer 3 → Layer 2 → Layer 1 → Weights The signal carries one question per weight: "How much did YOU contribute to this 4,489 loss?" Green = forward direction Red = backward blame direction
Step ④ — Gradient Computed Per Weight
Chain Rule — 3 steps: Step 1: dLoss/dPrediction = 2 × (267 − 200) = 2 × 67 = 134 Step 2: dPrediction/dWeight = Input = 1000 Step 3: Chain = 134 × 1000 = 134,000 ← Weight gradient = 134 × 1 = 134 ← Bias gradient 134,000 = how much W_sqft→N1 hurt the loss.
Step ⑤ — Weights Updated
W_new = W_old − (LR × Gradient) LR = 0.000001 W_sqft→N1: 0.300 − (0.000001 × 134,000) = 0.166 ✅ W_loc→N1 : 0.500 − (0.000001 × 938) = 0.499 ✅ W_sqft→N2: 0.100 − (0.000001 × 134,000) = −0.034 Bias N1 : 10.00 − (0.000001 × 134) = 9.999 ✅ Every weight nudged in the direction that reduces loss!

5
Gradient Descent — Learning Rate
💡 WHY: Gradient tells us which direction to move the weight. Learning rate controls how big that step is. Wrong learning rate = network never learns.
🏔️ MOUNTAIN — FINDING THE LOWEST VALLEY
You are blindfolded on a hill. Goal = reach lowest point = lowest loss.

Gradient = slope under your feet (which way is down)
Learning Rate = size of each step you take
Learning Rate — Using Our Actual Gradient (134,000)
LR=1.0 (too large): W = 0.3 − (1.0 × 134,000) = −133,999 ← exploded! LR=0.0000000001 (too small): W = 0.3 − (0.0000000001 × 134,000) = 0.2999 ← barely moved! LR=0.000001 (appropriate): W = 0.3 − (0.000001 × 134,000) = 0.166 ← good step ✅
6
Vanishing Gradient — Watch Signal Die
💡 WHY: Gradient flows backwards from output to input. At each layer it gets multiplied by a small number and shrinks. By Layer 1 it is nearly zero — that layer stops learning entirely.
Gradient Starts at Output — Strong Signal
Backprop begins at the output layer. Gradient = 700 ← strong signal This signal must travel ALL the way back to Layer 1 to update early weights. Watch what happens as it passes each layer...
Reaches Layer 3 — Still OK
Output gradient: 700 × Sigmoid derivative: 0.1 = Layer 3 gradient: 70 Still usable. Layer 3 can learn.
Reaches Layer 2 — Getting Weak
Layer 3 gradient: 70 × Sigmoid derivative: 0.1 = Layer 2 gradient: 7 Getting small. Layer 2 learns slowly.
Reaches Layer 1 — Nearly Dead
Layer 2 gradient: 7 × Sigmoid derivative: 0.1 = Layer 1 gradient: 0.7 Almost zero. Layer 1 barely updates. Weight change = 0.0001 × 0.7 = 0.00007 That is nearly nothing!
Layer 1 is Dead — The Big Problem
Layer 1 gradient ≈ 0 → weight barely changes Layer 1 learns BASIC patterns: → "location matters" → "larger houses cost more" If Layer 1 never learns these basics, Layers 2, 3 build on garbage. The entire network fails. Solution: ReLU activation (next tab →)
7
ReLU — Watch Numbers Transform
💡 WHY: After each neuron calculates its value, ReLU decides: keep it or kill it. Negative = useless signal = set to 0. Positive = useful = pass through unchanged.
Raw Neuron Outputs — Before ReLU
After calculations, Layer 1 produced: N1 = 313.5 ← positive N2 = 110.6 ← positive N3 = −85.0 ← NEGATIVE! Without ReLU: all 3 pass to next layer. Negative values confuse the network. Tap → Apply ReLU to see what happens.
ReLU Applied — max(0, x)
ReLU Rule: If x > 0 → keep it (gate OPENS) If x ≤ 0 → make it 0 (gate CLOSES) N1: max(0, 313.5) = 313.5 ✅ gate opens N2: max(0, 110.6) = 110.6 ✅ gate opens N3: max(0, −85.0) = 0 ❌ gate CLOSES
What Passes to Next Layer
313.5 → passes to Layer 2 ✅ 110.6 → passes to Layer 2 ✅ 0 → passes to Layer 2 (but has no effect) N3 is now "dead" for this input. It contributes nothing to the next layer. Only meaningful signals flow forward.
Why ReLU Fixes Vanishing Gradient
Old function (Sigmoid) squished everything: Gradient: 700 × 0.2 × 0.2 × 0.2 = 5.6 ← dying ReLU derivative = 1 for positive values: Gradient: 700 × 1.0 × 1.0 × 1.0 = 700 ← alive! ✅ ReLU used: INSIDE network after every hidden layer NOT used: At output (use Softmax there for classification)
8
Softmax — Watch Scores Become Probabilities
💡 WHY: At the OUTPUT layer for classification, we need probabilities not raw scores. Softmax converts any numbers into percentages that always add to exactly 100%.
Raw Scores — Network Output Before Softmax
Network classified an image. Raw output scores: Cat = 8.5 Dog = 3.2 Bird = 1.1 These are just numbers. Not probabilities. We cannot say "84% cat" yet. Tap → Apply Softmax to convert them.
Softmax Formula Applied
Formula: P(x) = e^x / (e^8.5 + e^3.2 + e^1.1) e^8.5 = 4914.8 e^3.2 = 24.5 e^1.1 = 3.0 Total = 4942.3 Cat: 4914.8 / 4942.3 = 0.84 = 84% Dog: 24.5 / 4942.3 = 0.13 = 13% Bird: 3.0 / 4942.3 = 0.03 = 3% All add to 1.0 = 100% ✅
Final Probabilities — Network's Answer
Cat = 84% ← WINNER 🏆 Dog = 13% Bird = 3% ───────────── Sum = 100% ✅ Network says: "This is a Cat" Confidence: 84%
When To Use Softmax vs Nothing
Classification (pick ONE from many): Cat / Dog / Bird → USE Softmax ✅ Spam / Not Spam → USE Softmax ✅ Regression (predict a number): House Price $199k → NO Softmax Temperature 36.5° → NO Softmax ReLU vs Softmax location: ReLU → after every HIDDEN layer Softmax → only at OUTPUT layer for classification
9
Batch Normalization — Watch Values Stabilize
💡 WHY: When neuron outputs are wildly different in scale, the next layer struggles to learn. Batch Norm brings all values to a stable centered range — like tuning all instruments to the same pitch before playing.
Wild Values Entering Next Layer
Layer 1 outputs (before normalization): N1 = 50,000 ← enormous! N2 = 0.003 ← microscopic! N3 = 847 ← medium These go into Layer 2 as inputs. Layer 2 is completely confused by these wildly different scales.
The Problem This Causes
Layer 2 tries to learn weights for these inputs: N1=50,000 → weight must be tiny (like 0.000001) N2=0.003 → weight must be huge (like 10,000) N3=847 → weight must be medium Gradients become unstable. Some explode. Some vanish. Network learns very slowly or not at all. It's like trying to measure both a virus and a mountain with the same ruler.
Batch Norm Formula Applied
Step 1: Find mean mean = (50000 + 0.003 + 847) / 3 = 16,949 Step 2: Find std deviation = 23,094 Step 3: Normalize each value x_norm = (x − mean) / std_deviation N1: (50000 − 16949) / 23094 = +1.8 N2: (0.003 − 16949) / 23094 = −1.2 N3: (847 − 16949) / 23094 = −0.6
Result — All Values in Healthy Range
Before: 50,000 0.003 847 ← chaotic After: +1.8 −1.2 −0.6 ← stable ✅ All values now centered around 0. Layer 2 can learn with consistent weights. Training becomes faster and more stable. Applied after EVERY layer during forward pass. One of the most important tricks in deep learning.
10
Residual Connections — Watch the Skip
💡 WHY: Normal path loses gradient at every layer. Skip connection sends gradient directly — bypassing all layers. Layer 1 always gets a strong signal no matter how deep the network.
Normal Path — Gradient Travels Every Layer
Backprop signal starts at output. Must pass through EVERY layer to reach Layer 1: Output → L3 → L2 → L1 At each layer it gets multiplied by ~0.1 Tap → Signal Dies to see what happens.
Signal Shrinks at Every Layer
Output: grad = 700 Layer 3: grad = 700 × 0.1 = 70 Layer 2: grad = 70 × 0.1 = 7 Layer 1: grad = 7 × 0.1 = 0.7 ← dead! Layer 1 weight update ≈ nothing. Now see how skip connection solves this.
Skip Connection Added — Direct Highway
A shortcut wire is added from L3 directly to L1. Gradient skips L2 entirely. Skip path: Output → directly to L1 grad = 700 ← unchanged! ✅ No multiplication. No shrinking. Signal arrives at full strength.
Both Paths Combine at Layer 1
Normal path arrives: grad = 0.7 (weak) Skip path arrives: grad = 700 (strong) ───────────────────────────────── Combined at Layer 1: grad = 700.7 ✅ Layer 1 now receives strong gradient. It learns properly regardless of depth! Used in ResNet (2015) — enabled 152-layer networks. This is why modern networks can be so deep.

Weight & Bias Learnable params, random init Forward Pass Data flows input → output Loss (MSE) (Pred−Target)² → error score Backpropagation Chain rule → gradient per weight Gradient Descent W -= LR × gradient Vanishing Gradient Signal dies in early layers ReLU Gradient=1 → no vanishing Softmax Logits → probability distribution Batch Normalization Stabilizes layer activations Residual Connections Skip paths → gradient always flows These are the foundational components of modern deep learning.
