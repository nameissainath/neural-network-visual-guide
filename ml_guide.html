Linear & Logistic Regression are simple math equations with no neural network. Deep Learning models use layers of neurons to learn complex patterns — ANN for numbers, CNN for images, RNN/LSTM for sequences, and Transformers for everything at scale.

01 Linear Regression

📈 What is it?

Predicts a continuous number using a straight line equation. No neural network!

Formula: Output = w1×x1 + w2×x2 + bias Example: Predict House Price 🏠 Input: Size=1000sqft, Rooms=3 Output: $200,000 Equation: Price = w1×(Size) + w2×(Rooms) + bias Price = 150×1000 + 10000×3 + 20000 Price = $200,000 ✅

💼 Interview answer:

Linear Regression finds the best-fit straight line through data points. Output is always a continuous number. It uses Ordinary Least Squares to minimize the difference between predicted and actual values. Used when relationship between input and output is approximately linear.

02 Logistic Regression

✅ What is it?

Predicts a category (Yes/No). Uses Sigmoid to squish output between 0 and 1.

Formula: Output = Sigmoid(w1×x1 + w2×x2 + bias) Example: Pass or Fail? 🎓 Input: Study hours=7, Sleep=8 Linear: z = 0.5×7 + 0.3×8 = 5.9 Sigmoid: σ(5.9) = 0.997 → 99.7% → PASS ✅ Input: Study hours=1, Sleep=3 Linear: z = 0.5×1 + 0.3×3 = 1.4 Sigmoid: σ(1.4) = 0.80... wait with negative bias → 0.05 → FAIL ❌

03 Activation Functions

σ Sigmoid

Formula: 1 / (1 + e^(-x)) Range: 0 → 1 Input: 2 → 0.88 (88%) Input: -3 → 0.05 (5%) Input: 0 → 0.50 (50%) Use: Output layer for Yes/No

⚡ ReLU

Formula: max(0, x) Range: 0 → ∞ Input: 3 → 3 (keep) Input: -5 → 0 (kill) Input: 7 → 7 (keep) Use: Hidden layers in ANN/CNN

🎯 Softmax — Multi-class Example 🍎🍌🍇

04 ANN — Artificial Neural Network

🧠 Structure

INPUT LAYER HIDDEN LAYER 1 HIDDEN LAYER 2 OUTPUT Age ──────────────┐ ├──→ [N1] ──┐ Experience ───────┤ ├──→ [N4] ──┐ ├──→ [N2] ──┤ ├──→ $75,000 Education ────────┤ ├──→ [N5] ──┘ └──→ [N3] ──┘ Each connection has a WEIGHT (learned during training!) Each neuron applies: output = ReLU(w1×in1 + w2×in2 + bias)

💼 Why ANN > Linear Regression for salary?

Linear Regression assumes salary grows in a straight, predictable way. ANN finds hidden non-linear relationships — e.g., Young (25) + High Experience (8yrs) = $90k, but Old (50) + Same Experience = $60k. A straight line can't capture this. ANN's hidden layers and activation functions model these complex curves.

05 Forward & Backward Pass

➡️ Forward Pass

Data flows INPUT → OUTPUT Input: [Age=25, Exp=5, Edu=16] ↓ Hidden Layer 1: N1 = ReLU(w×25 + w×5 + b) = 0.7 N2 = ReLU(w×25 + w×5 + b) = 0.4 ↓ Hidden Layer 2: N3 = ReLU(w×0.7 + w×0.4) = 0.6 ↓ Output: Salary = 0.6 × w + bias = $72,000 Actual Salary = $75,000 Loss = (75000-72000)² = 9,000,000

⬅️ Backward Pass (Backprop)

Error flows OUTPUT → INPUT Loss = 9,000,000 Step 1: How much did output weight cause this error? → Calculate gradient Step 2: How much did Layer2 weights cause this error? → Chain rule! Step 3: How much did Layer1 weights cause this error? → Chain rule again! Update: w = w - 0.01 × gradient (0.01 = learning rate) Repeat → Loss gets smaller! ✅

🔗 Chain Rule Simply

Think of it like blaming in a team: Goal scored ← Striker ← Midfielder ← Defender If goal missed: Blame Striker: 80% responsible Blame Midfielder: 15% responsible Blame Defender: 5% responsible Each gets "blame" = gradient Each adjusts their play = weight update That is backpropagation! 🎯

💼 Interview answer:

Backpropagation uses the chain rule of calculus to compute gradients of the loss with respect to each weight. Starting from the output layer, it propagates the error backward, calculating how much each weight contributed to the error. Weights are then updated using gradient descent: w = w - lr × gradient.

06 CNN — Convolutional Neural Network

🖼️ Why not just ANN for images?

Problem with ANN on images: 64×64 image = 4,096 pixels Each pixel → separate neuron 4096 neurons × 4096 = 16M connections! Too heavy! Too slow! ❌ Also ANN sees pixels as FLAT list: [255, 128, 64, 200, ...] No idea where things ARE! ❌ CNN Solution: Use small filters that SLIDE over image Detect local patterns (edges, shapes) Much fewer connections! ✅

🔍 How CNN Filter Works

5×5 Image of a face: ⬛⬛⬛⬛⬛ ⬛⭕⬛⭕⬛ ← eyes ⬛⬛⬛⬛⬛ ⬛⬜⬜⬜⬛ ← mouth ⬛⬛⬛⬛⬛ CNN slides a 3×3 filter window: Step 1: top-left patch Step 2: slide right ⬛⬛⬛ ⬛⬛⬛ ⬛⭕⬛ → score: 0.2 ⭕⬛⭕ → score: 0.9! 👀 ⬛⬛⬛ ⬛⬛⬛ High score = pattern found! Filter learns to detect: edges, eyes, shapes...

07 RNN & LSTM

📝 RNN — Short Memory

Sentence: "I am hungry want eat" ANN/CNN (no memory): "eat" → forgets "hungry" ❌ RNN (has memory): "I" → h1 (memory) "am" → h2 (uses h1) "hungry" → h3 (uses h2) "want" → h4 (uses h3) "eat" → h5 (uses h4) → remembers "hungry"! ✅ Problem: Long sentences Early words get forgotten! ❌ = Vanishing Gradient Problem

💾 LSTM — Long Memory

3 special gates: 🗑️ Forget Gate: What to throw away? "the", "a", "is" → forget 💾 Input Gate: What to remember? "hungry" → keep! ✅ 📤 Output Gate: What to output now? Context for current word Result: Remembers across very long sentences! ✅ Still sequential = slow 🐢

08 Transformer — Step by Step

📌 Key Idea

LSTM problem: "I am hungry ... [100 words] ... want to eat ___" Reads word by word → forgets "hungry" 🐢❌ Transformer solution: Reads ALL words at SAME TIME ⚡ Every word sees every other word! "eat" directly sees "hungry" ✅
1️⃣
Word Embedding
Convert words to vectors: "hungry" → [0.9, 0.7, 0.2]
2️⃣
Positional Encoding
Add position info using Sin/Cos. Same word at pos 2 ≠ pos 5
3️⃣
Self Attention (Q,K,V)
Every word attends to every other. "eat" focuses 80% on "hungry"
4️⃣
Add & Layer Norm
Residual connection + normalize to keep numbers stable
5️⃣
Feed Forward ANN
Each word thinks deeply about itself independently
6️⃣
Add & Layer Norm
Again stabilize numbers
🔁
Repeat N times
GPT-3: 96 blocks. More blocks = deeper understanding
7️⃣
Linear + Softmax
Convert final vector to word probabilities → predict next word

🎯 Self Attention Q K V — Simple Example

Sentence: "I am hungry" Each word gets 3 vectors: "hungry" → Q3 (Query: what am I looking for?) → K3 (Key: what do I contain?) → V3 (Value: what info do I give?) Attention Score = Q × K: "hungry" Q3 × K1("I") = 0.2 → 15% "hungry" Q3 × K2("am") = 0.1 → 10% "hungry" Q3 × K3("hungry") = 0.9 → 75% ← focus here! Apply Softmax → probabilities Final = weighted sum of Values: 15% × V1 + 10% × V2 + 75% × V3 = Rich context vector for "hungry"! ✅

💼 Interview answer for Transformer:

Transformer (2017, "Attention is All You Need") replaced RNN/LSTM by reading all tokens simultaneously using Self-Attention. Q×K gives attention scores (how related are two words), Softmax normalizes them, then V is weighted by these scores. This runs in parallel (fast ⚡), captures long-range dependencies (no forgetting), and scales with data. Used in GPT, BERT, Claude, etc.

09 Batch Norm vs Layer Norm

📦 Batch Normalisation

Normalises ACROSS sentences: Sentences in batch: S1: "I am hungry" → feature1: 0.9 S2: "I love food" → feature1: 0.3 S3: "I want water" → feature1: 0.6 Mean = 0.6 Normalize all to same range ✅ Problem: needs large batch Small batch = unstable ❌ Used in: CNN

📋 Layer Normalisation

Normalises WITHIN one word: "hungry" vector: [0.7, 0.4, 0.2, 0.9] Mean = (0.7+0.4+0.2+0.9)/4 = 0.55 Normalize → [0.3,-0.2,-0.5,0.5] ✅ Works on each word independently! No dependency on batch size! ✅ Stable even with 1 sentence! ✅ Used in: Transformer ✅

🔄 Residual Connection

Problem: Deep networks lose original info! Solution: Add input to output! Input to Self-Attention: [0.9, 0.7, 0.2] Output of Self-Attention: [0.5, 0.3, 0.8] ↓ ADD TOGETHER Residual output: [1.4, 1.0, 1.0] ↓ Layer Norm Stable vector: [0.8, 0.5, 0.5] ✅ Original info never lost! Gradients flow better in backprop!

💼 Why Layer Norm in Transformer?

Sentences have variable lengths, making Batch Norm unstable (statistics change per batch). Layer Norm normalizes each token's vector independently — no dependency on other sentences or batch size. This makes training stable regardless of sequence length.
